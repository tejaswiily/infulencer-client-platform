# Collab Sphere

A full-stack influencer-client collaboration platform built using the MERN stack with secure authentication, campaign management, and real-time communication features.

## Features
- JWT-based authentication and authorization
- Influencer-client collaboration workflows
- Real-time messaging using WebSockets
- Campaign management dashboard
- REST API integration
- MongoDB database support

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Socket.io

## Installation

```bash
npm install
```

## Run Project

Frontend:
```bash
npm start
```

Backend:
```bash
node server.js
```
